# Support

ResearchWitness is a research-preview open-source project.

## Questions and reproducible bugs

Use GitHub Issues for public, non-sensitive questions and reproducible defects. Prefer synthetic or already-public evidence bundles.

## Verifier proposals

Use the **Verifier request** issue form. A proposed verifier should have deterministic semantics, an explicit scope, hard resource bounds, and positive/negative validation cases.

## Security and confidential material

Do not attach unpublished papers, private author correspondence, credentials, personal information, or confidential evidence to a public issue. Follow [`SECURITY.md`](SECURITY.md) for security reports.

## Scientific interpretation

ResearchWitness does not provide peer review, legal advice, publication adjudication, or a misconduct determination. A formalization-level result should be interpreted only within the scope recorded in its evidence capsule.
