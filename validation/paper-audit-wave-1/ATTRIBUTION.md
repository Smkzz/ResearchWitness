# Source attribution and reuse notes

This development set does not redistribute full papers or PDFs. `cases.json` records the exact Europe PMC JATS endpoint, retrieval date, PMCID, DOI, version hash, author list, title, journal, and license statement for each original. It also pins the correction records used as positive ground truth. `report.json` files preserve only short source anchors needed to review the candidate.

The nine articles and three correction notices whose captured JATS metadata specifies **CC BY 4.0** are attributed below. The depressive-symptoms correction (PMC6991292, DOI 10.1001/jamanetworkopen.2019.20603) is attributed by title and DOI in the manifest; its JATS license statement says “CC-BY License” but does not specify a version, so the correction full text is not included or quoted here.
