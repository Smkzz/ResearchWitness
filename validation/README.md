## Engineering and documentation

CI evaluates the exact revision, supported Python/OS matrix, static checks, core
coverage, manifests, deterministic artifacts and clean installation. Documentation
tests exercise fixed synthetic commands, source anchors, versions and maintained
links; agent-plan tests check discoverability and task dependency consistency.
They do not execute arbitrary Markdown or prove scientific findings.

Exact new qualification belongs to the relevant PR/main run receipt. Snapshot test
counts/hashes must not be reused as later results. Agents can review and merge
qualified engineering changes without routine human approval, but cannot replace
missing evidence with confidence or bypass a security boundary.
