## What RW-01P changes — and what it does not

RW-01P selectively ports the previously unmerged PRISMA mapper to the
**current installed** `audit-jats --include-prisma-flows` path. It checks
one explicitly labelled single-body-paragraph record-removal relation
using the current original-byte XML projection and independently
replayable review bundles. This is a real **engineering capability
expansion**, not an observed improvement in the 33-document historical
corpus: that corpus had no eligible PRISMA correction-backed positive,
and its original source bytes were not newly obtained or reprocessed.

Do not merge the old PR #5–#12 stack wholesale, relax real-paper
eligibility to increase apparent recall, or reclassify the old
developer-exposed correction cases as new untouched holdouts.
