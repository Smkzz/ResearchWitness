## RW-01D: source-mapped table projection (candidate)

The installed audit-jats --include-structure optionally projects the existing
original-byte JATS parser to the immutable PaperDocument table model. Header
references, row/column spans, original XML offsets, caption denominator cues,
numeric surface forms and footnotes are preserved without guessing scientific
context. The existing detector's conditional/unknown denominator decisions stay
unresolved. See [the table model contract](JATS_TABLE_PROJECTION.md).

This is partial RW-01 work. Rich legacy flow/ratio integrations and protected
custody remain pending. Qualification belongs to the exact PR head; a proposal
is not independent scientific accuracy evidence.

## Paired development comparison slice - 2026-10-26

RW-04C adds `tools.paired_development_comparison`, a checkout-only,
deterministic comparison of two externally pinned registered development runs.
It preserves all work-family denominators, negative-family alarms before
certificate validation, missing results and resource-budget equivalence.
The output is a descriptive comparison of declarations, not a scientifically
independent accuracy estimate. RW-04 remains incomplete pending independent
source/certificate adapters, sample registration and sealed evaluation.

## Installed JATS review candidate - 2026-10-26

PR #22 introduces the installed `audit-jats` and `replay-jats` CLI using
the current bounded JATS parser as one implementation shared with the checkout
tool. Results use immutable source hashes, exact source offsets, JSON/HTML and a
recomputed manifest-validated replay. Decimal context mutation does not silently
change arithmetic. Denominator and scientific interpretation ambiguity still
abstain. Engineering qualification of the exact proposed head is recorded in
PR #22; the historical 752-test uncommitted result is not a CI receipt.

This is no sealed research evaluation, PDF isolation or scientific discovery proof.
No author contact, provider billing or public package publication is performed.

## Source-bound execution slices - 2026-10-25

RW-01B preserves the legacy immutable canonical model and bridges the current JATS
detector to exact original XML element anchors and numeric assertions. Unknown
context, denominator ambiguity and conditional results remain explicit. Separate
integer arithmetic replay checks resolved numerical relationships. The legacy
normalizing parser and full installed paper-audit stack remain unmerged.

RW-04B adds a fixed registered JATS runner and runnable synthetic example. Unlike
the earlier receipt-only scorer, it actually captures source bytes, runs the source
adapter in a pinned-code subprocess, replays arithmetic and records outcomes.
It retains known alarms before semantic validation, preserves registered denominators,
requires the registered target rather than substituting another finding, and
supports read-only interrupted-run recovery. Its code snapshot and pipe/time caps
are not an OS security sandbox, source authentication or independent adjudication.
See [the runner guide](JATS_DEVELOPMENT_RUNNER.md),
[integration map](INTEGRATION_MAP.md) and
[implementation receipt](IMPLEMENTATION_2026-10-25.md).

Both RW-01 and RW-04 remain partial. Rich table/source-detector consolidation,
installed CLI wiring, formal comparative registration, reviewed labels and sealed
scientific evaluation are still pending. No package/tag release, protected-data
access, paid provider, author contact or native PDF/custody activation is claimed.
Exact candidate and post-merge qualification is recorded in the containing PR,
not invented in a document written before CI.

## Current operating policy

Agents make ordinary technical decisions, obtain scoped AI review, perform qualified
merges and prepare scoped releases without routine human signoff. Only new safety
authority or actual unauthorized spending requires escalation. Scientific evidence
is a gate, not a request for an opinion. See [DECISIONS.md](DECISIONS.md).
