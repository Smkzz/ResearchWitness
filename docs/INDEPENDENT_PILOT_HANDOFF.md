# Independent development-pilot source and review handoff

**Scope:** Developer-exposed, **not blinded** source pilot for
[RW-01O #35](https://github.com/Smkzz/ResearchWitness/issues/35) and
[RW-01Q #50](https://github.com/Smkzz/ResearchWitness/issues/50).
**Status:** Independent scientific review and actual original sources
remain uncollected. This is an invitation-ready operational protocol,
not a claim that any collaborator is engaged or authorized.

ResearchWitness is an open-source developer project; **EUR 0
incremental spending authority** applies. Never upload private source
bodies, private reviewer statements, keys, unpublished manuscripts or
sensitive correspondence into GitHub, Actions or public issues.

## Separation of duties

| Role | Acceptance evidence | Limit |
|---|---|---|
| Authorized source operator | Private original response bodies, actual provider request/status/time receipt, byte hash, version, rights and complete failures | Use existing allowed egress/custody only; no CI HTTP, proxy bypass, fabricated response or display derivative replacing original bytes |
| Source-context reviewer A | Independently interpret original population, unit, denominator, statistics, byte anchors, exceptions and ambiguity | When practicable, review original context before seeing correction answer; never copy developer candidate |
| Correction/lineage reviewer B | Independently verify original-to-correction article/version relation, scope, correction type and possible alternatives | Truly separate reviewer/session, not another prompt in a shared AI workspace |
| Scientific reconciler | Preserve two reports, disagreements, abstentions, exclusions, lineage and unresolved reviews | Consensus is not automatic scientific truth |
| Research coordinator | Frozen exact selected source frame, full attempt ledger, pinned comparison arms and **sanitized aggregate** report | No retrospective case dropping, no promotion to sealed study or accuracy claim |

The pilot should use **2–5 declared scientific work families**; an
article, its correction, revisions and supplements are **not**
automatically independent work families. Exposure, correction awareness
and overlapping datasets must be recorded before metrics.

## Execution order

1. **Private preselection:** Record the exact source-version/PMC OAI
   identities and selected-but-unattempted records using
   [PMC_SELECTION_FRAME.md](PMC_SELECTION_FRAME.md). Save independent
   frame commitments before acquisition. A self-pinned hash does not
   prove genuine external preregistration.
2. **Rights and transport:** Verify actual licence and private storage
   approval per article; then acquire *complete original*
   OAI-PMH `GetRecord` raw responses in an already-authorized
   environment. This is **not** the same representation as
   Europe PMC `fullTextXML`, current provider-rendered DOM text or
   original 2026 historical transport evidence.
3. **Frame-bound offline replay:** Follow
   [PMC_PILOT_LEDGER.md](PMC_PILOT_LEDGER.md) and the
   selection-frame CLI. Preserve not-attempted, provider errors, parser
   refusals, licence exclusions and review-pending rows; report the full
   denominator, not successes only.
4. **Separate scientific interpretation:** Reviewers A and B must
   state source version and directly anchored context, classify
   whether the arithmetic relation truly applies, identify every
   alternative denominator and document correction specificity.
   Independent humans are required for scientific truth claims.
5. **Reconciliation:** If reviewers disagree, retain the conflict.
   Exclude only by previously declared criteria and do not convert
   unresolved candidate alerts into established publication errors.
6. **Method comparison:** Only after permitted source/version/review
   evidence exists, run an honestly precommitted same-source baseline
   and candidate with explicit costs, family counts, abstentions,
   false alarms and actual unsupported types. Protected-custody and
   Wave 3 gates remain separate.

## Reviewer questions

- Which exact version and source representation was inspected?
- Which original text/cell defines the statistical unit and population?
- Do varying subgroup Ns, weighting, rounding, missingness, merged cells,
  adjusted models, repeated measures or multiple cohorts matter?
- Is the proposed discrepancy a provable arithmetic mismatch, a
  typography correction, an ambiguous interpretation, a source
  extraction failure, or unsupported by the exact contract?
- What source-specific assumption, if false, would invalidate the
  proposed conclusion? Keep both positive and negative evidence.
- Does the published correction refer to the very same claim,
  version, scope and independent work family?

Review answers should reside privately and be linked to real source
bytes. An unsigned AI summary or source SHA alone does not establish
reviewer identity, licence, source authenticity or scientific truth.

## Concrete unblock condition

Actual permission-cleared original response bytes for at least one
preselected real source/version chain, plus authentic transport evidence
and independently grounded source review, constitute real progress.
A small exposed pilot is **not** a powered confirmatory benchmark.
Historical Europe PMC original recovery remains **0/13**, and an
unverified current source cannot replace a missing historical body.

Potential contributors can express expertise and interest in a **public
issue without article texts or private research data**. Specific
licensed sources and review materials must move only through separately
approved private custody. No contributor is presumed contracted,
compensated, or an independent scientific reviewer until verified.
