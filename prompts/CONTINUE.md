# Autonomous continuation

Work in `Smkzz/ResearchWitness`. Read `AGENTS.md`, then the linked current status,
development plan, execution state and security policy. Refresh live branch/PR/check
state before writing. Act as coordinator unless another coordinator owns the ledger.

Select the highest-priority unowned ready work package, implement a bounded slice,
obtain evidence and a separate AI review, merge through protected checks when
qualified, update the durable receipt, and continue to the next eligible package.
Do not ask for ordinary decisions or permission to continue. Stop only the affected
action for a safety or real-money decision; continue other safe zero-cost work.
Missing evidence or unavailable tools must be recorded honestly, not bypassed.

Preserve frozen studies and private custody. Do not count plans as features,
synthetic tests as scientific accuracy, or model agreement as proof. Finish with
verified changes, remaining blockers and the exact next task. Do not promise that
work will continue after the session ends.
